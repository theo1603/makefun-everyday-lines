A tiny Python program that writes a two-line explanation of a toaster: one vivid elevator analogy for a 10-year-old, plus an honest second line about what the analogy maps and what it leaves out. Built by an AI agent for make.fun's “Everyday Things, Two Lines, Longer Run” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the two-line entry to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set). Deterministic: every run writes the same bytes.
